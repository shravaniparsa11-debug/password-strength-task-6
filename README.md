# Task 6: Create a Strong Password and Evaluate Its Strength

## Objective
To understand what makes a password strong and evaluate password strength using an online password strength checker.

## Tool Used
Password Strength Checker: passwordmeter.com

## Password Strength Evaluation

| Test Password | Length | Result |
|---|---:|---|
| hello123 | 8 | Very Weak |
| Hello123 | 8 | Very Weak |
| Hello@12345 | 11 | Very Weak |
| #Hello.@12&45*65 | 16 | Very Strong |

## Observations

- `hello123` was identified as a commonly used password.
- `Hello123` was also rated Very Weak.
- `Hello@12345` used all four character types, but a common number pattern was detected.
- `#Hello.@12&45*65` was rated Very Strong.
- The strongest test password had excellent length and no common patterns.

## Common Password Attacks

### 1. Brute Force Attack
An attacker tries many possible password combinations until the correct password is found.

### 2. Dictionary Attack
An attacker tries passwords from lists of commonly used words and passwords.

## Password Best Practices

- Use long and unique passwords.
- Use a combination of uppercase and lowercase letters, numbers, and symbols.
- Avoid common words and predictable patterns.
- Avoid personal information such as names and birthdays.
- Do not reuse passwords across different accounts.
- Enable multi-factor authentication (MFA).
- Use a trusted password manager when appropriate.

## Conclusion

Password length, uniqueness, and unpredictability are important for password security. A strong password is more resistant to password-guessing attacks. Using strong unique passwords together with MFA provides better account security.
